# МХБ багцын хяналтын самбар

Өдөр бүр МХБ-ийн үнийн өгөгдлийг татаж, багцын байдлыг тооцоолж, вэб хуудас болгон
шинэчилдэг систем. GitHub Actions дээр ажиллах тул таны компьютер унтраалттай байсан
ч ажиллана. Үр дүнг утас, компьютерээс ямар ч үед нээж харна.

## Файлууд

| Файл | Үүрэг |
|---|---|
| `config.json` | Таны эзэмшил, зорилтот жин, сарын дүн. **Зөвхөн үүнийг засна.** |
| `update.py` | Өдөр бүр ажиллаж өгөгдөл татаж, хуудсыг зурна |
| `mse_scraper.py` | open.mse.mn-ээс өгөгдөл уншина |
| `.github/workflows/daily.yml` | Автоматаар ажиллах хуваарь |
| `data/prices.csv` | Хуримтлагдсан үнийн түүх (автоматаар үүснэ) |
| `docs/index.html` | Хяналтын самбар (автоматаар үүснэ) |

## Нэг удаагийн тохиргоо

**1. GitHub акаунт нээх.** github.com дээр бүртгүүлнэ. Үнэ төлбөргүй.

**2. Репозитор үүсгэх.** Баруун дээд булангийн `+` товчноос `New repository`.
Нэрийг `mse-tracker` гэж өгөөд `Public` сонгоно. Public байх нь чухал: үнэгүй
төлөвлөгөөнд Pages болон Actions зөвхөн нээлттэй репод бүрэн ажиллана.

> Репод байгаа `config.json` дотор масштаблагдсан тоо бичигдсэн тул таны бодит дүн
> хэнд ч харагдахгүй. Дэлгэрэнгүйг доорх "Дүнгээ нуух" хэсгээс уншина уу.

**3. Файлуудыг байршуулах.** `Add file` -> `Upload files` товчоор бүх файлыг чирж
оруулна. `.github/workflows/daily.yml`-ийг байршуулахдаа хавтасны бүтэц хадгалагдсан
эсэхийг шалгаарай (файлыг чирэхийн оронд `Add file` -> `Create new file` дээр
`.github/workflows/daily.yml` гэж бичээд агуулгыг хуулж тавих нь найдвартай).

**4. Pages идэвхжүүлэх.** Репогийн `Settings` -> зүүн талын `Pages` ->
`Source` хэсгээс `GitHub Actions` сонгоно.

**5. Эхний удаа гараар ажиллуулах.** `Actions` таб -> зүүн талаас
`Өдөр тутмын шинэчлэл` -> `Run workflow`. 2-3 минутын дараа дуусна.

Дууссаны дараа хуудас `https://<таны-нэр>.github.io/mse-tracker/` хаягаар нээгдэнэ.
Утсандаа хавчуулга хийж тавиарай.

## Хэрхэн ашиглах

Өдөр бүр ажиллаж, өгөгдөл хуримтлуулна. Танд хийх зүйл алга.

Сард нэг удаа хуудсыг нээж, дээд талын жагсаалтын дагуу брокерийн аппаараа захиалга
өгнө. Дараа нь `config.json` дотор шинэ тоо ширхэг, өртгийг нэмж бичнэ.

**Хязгаарын захиалга (limit order) ашиглаарай.** Жагсаалт дээрх "дээд үнэ" бол
өмнөх хаалтаас 1% өндөр үнэ. Нимгэн арилжаатай зах зээлд зах зээлийн захиалга өгвөл
та өөрөө үнийг өсгөх эрсдэлтэй.

## Дүнгээ нуух

Нээлттэй репод бодит эзэмшил харагдахгүй байхаар хоёр файл ашиглана.

| Файл | Хаана байх |
|---|---|
| `config_real.json` | Бодит тоо. **Зөвхөн таны компьютер дээр.** `.gitignore`-д орсон |
| `config.json` | Масштаблагдсан тоо. Энэ нь репод очно |

Эзэмшлээ өөрчлөх бүрд:

```
python scale_config.py 7.4
```

`config_real.json` доторх тоог 7.4-т хуваан `config.json` үүсгэнэ. Дараа нь зөвхөн
`config.json`-ыг репод байршуулна.

**Коэффициентээ өөрөө сонгоорой.** Одоогоор жишээ болгон 7.4 гэж тохируулсан.
10 гэх мэт бүтэн тоо таамаглахад хялбар тул 6.3, 12.7 зэрэг өөрийн санасан тоог
хэрэглэвэл илүү. Хаана ч тэмдэглэхгүй, зөвхөн санаж байхад хангалттай.

Хуудас нээхэд эхлээд масштаблагдсан дүн харагдана. Доод талын "Хувийн коэффициент"
талбарт өөрийн тоогоо оруулбал бүх дүн бодит болно. Энэ тоо таны хөтөч дээр
хадгалагдах тул дахин оруулах шаардлагагүй. Репод, серверт хаана ч илгээгдэхгүй.
Өөр хүн хуудсыг нээвэл зөвхөн масштаблагдсан тоог харна.

Хувь хэмжээ, үнэ, ногдол ашгийн өгөөж зэрэг нь масштабаас хамаардаггүй тул
коэффициент оруулаагүй ч зөв харагдана.

## Тохируулах

`config.json` дотор:

- `monthly_budget` — сард оруулах дүн
- `buys_per_month` — сард хэдэн хувьцаа авах (3 байх нь шимтгэлийн хувьд тохиромжтой)
- `target_weight` — зорилтот жин хувиар. `0` бол эзэмшсээр байх боловч шинээр нэмэхгүй
- `dividend_per_share` — сүүлийн жилийн ногдол ашиг. Жил бүр 2-4 сард шинэчилнэ
- `alerts.daily_move_pct` — хэдэн хувийн хөдөлгөөнд анхааруулах

## Анхаарах

Өгөгдөл нь арилжаа хаагдсаны дараах (EOD) үнэ. Бодит цагийн ханш нээлттэй эх
сурвалжид байхгүй тул брокерийн аппаас харна.

`open.mse.mn` бол албан ёсны API биш. Сайтын бүтэц өөрчлөгдвөл `mse_scraper.py`
доторх уншигчийг шинэчлэх шаардлагатай. Хуудсан дээр "Өгөгдөл N хоногийн өмнөх
байна" гэсэн анхааруулга гарвал энэ шалтгаантай байж болно.

ERS, MFG хоёрын үнэ автоматаар татагдахгүй тул `config.json` доторх
`other_assets` хэсэгт гараар бичсэн. Заримдаа шинэчилж өгөөрэй.
